# School Metrics Reconciliation App

## How to run it

1. Open a terminal.
2. Go to the app folder:

```bash
cd /workspaces/elevate-215_2026/Workbench/Version\ 1
```

3. Create a virtual environment:

```bash
python3 -m venv .venv
```

4. Activate it:

```bash
source .venv/bin/activate
```

5. Install the app requirements:

```bash
pip install -r requirements.txt
```

6. Start the app:

```bash
streamlit run app.py
```

7. Open the link shown in the terminal, usually:

```text
http://localhost:8501
```
