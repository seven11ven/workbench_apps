# Setup

1. Open a terminal in the project folder:

```bash
cd /workspaces/elevate-215_2026/Workbench/version-2
```

2. Install dependencies:

```bash
npm install
```

3. Start the app:

```bash
npm run dev
```

4. Visit http://localhost:3000 in the browser.

5. To verify a production build, run:

```bash
npm run build
```
